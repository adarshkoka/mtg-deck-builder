Phase 2

Below I outline the plan for Phase 2 of development. 
These are the names of the views that I am designating within the application: Search Decks view, Decklist view, Card view, Synergies view, and Custom Deck view.

Find Synergies:

When Find Synergies is clicked for a Commander it should not show cards that are incompatible due to Colors or due to the Singleton rule (card is already in the custom deck).

Detected Keywords:

The detected keywords should be clickable and once clicked it should filter the cards on the Decklist view by that keyword while maintaining the separation of cards by their precon deck.

New Feature:
Once the Set Commander button is clicked, cards in the Decklist view that are incompatible due to Color should become greyed out.

Fix Bugs:

Clicking on a card from the Synergies view causes the Card view to display which is good, but the Synergies view disappears.

UI/UX Expansion:

The View Custom Deck screen should be displayed as small squares four on each row. Each square is for a card and should include an image of the card's art. 
Save Progress for the user's custom deck even if the application restarted.
Save Past searches for quick selection on the Search Decks view even if the application restarted. 
Download button on the Custom Deck view that downloads a simple text file showing the Commander and a numbered list of the cards in the deck.
Add a Button click effect and a neon flare effect around the card image when a card is added to deck. 
Add a Button click effect and Firework flare effect around the card image when Set as Commander button is clicked.
Color code the buttons of cards in the Decklist view based on their Mana color. If they are more than one color, the button should have a gradient of the colors it is.
