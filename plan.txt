Objectice: Develop a Single Page React application to aid in deckbuilding for the card game Magic: The Gathering.
The application will be built using React, Vite, Typescript, and Tailwind CSS.
The application will utilize the Scryfall API for retrieving data. 

Within the application the user can search for Preconstructed (Precon) Commander decks by searching the name of deck 
and selecting it from a dropdown.
The user should be able to select multiple decks. Once they are selected and the user clicks a button the 
application should retrieve the list of cards from each deck and the text of every card. 
The application should then present an organized list of cards from each deck. 

Clicking on a card should reveal the text of a card.

- The possible commanders in each deck according to the rules of Commander (Legendary Creatures) should be displayed at the top of the decklists
If a commander is selected by the user, in addition to showing the text as mentioned above, there should be a button which then identifies keywords
in the text of the Commander card. Keywords would be words that are important for the gameplay of Commander. 
For eaxmple: mill, artifact, sacrifice, junk, and roll dice.
The application will then identify all other cards in all of the selected Precon decks that have these keywords or could be key pieces for the Commander cards.
However, the identified cards must follow the rules of Commander, for example the cards must be the same colors of the Commander as per the rules of the game.

- When the user searches the name of the deck allow for dropdown results that have part of the name
of the deck or close enough. For example, if the user searches "Caesar" the dropdown should have a result for
the "Hail Caesar" deck. If the user searches for "meat" then there should be a result for the "Scrappy Survivors"
deck because Dogmeat is the primary Commander in the deck.

- The Rate limits of the Scryfall API will be followed

- The user will be able to select cards from the display and add to a decklist. 
The decklist must follow the restrictions of Magic the Gathering Commander Rules (deck size, colors, etc.)

User Experience: Prioritize smooth, responsive UX.
Accessibility: Develop with accessibility in mind.
Code Quality: Maintain clean, documented, modular code.
